# FN Builds S20+ arhvive (site)

A simple static site to list Fortnite builds, their changelist (CL), status, and download links.

*This source code is **100%** free and open source so enjoy :)*

## 🧱 Structure
- `index.html`: Main webpage
- `builds.js`: Contains build info
- `style.css`: Styling
- `README.md`: Info and setup guide

## 🌐 Hosting on GitHub Pages
1. Create a new repository (e.g. `fn-builds-archive`)
2. Upload all files
3. Go to **Settings → Pages**
4. Under "Source", select the `main` branch and `/ (root)` folder
5. Visit your site at `https://<username>.github.io/fn-builds-archive`
